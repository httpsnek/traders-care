# Первый взгляд (2026-09-26)

Сырые заметки. Основа для аудита на этапе 1.

## traderscare.io/ru — что на странице

Всего 4 блока:
1. Hero в стеклянной карточке: надзаголовок «БЕСПЛАТНЫЕ ИНСТРУМЕНТЫ ДЛЯ ТРЕЙДЕРОВ · БЕЗ РЕГИСТРАЦИИ», H1 «Рабочее место трейдера», подзаголовок, кнопки «Начать бесплатно» / «Проп-фирмы» / «Полезные инструменты» + ссылка «Войти в воркспейс →».
2. «Всё для системного трейдера» — 6 карточек с иконкой (журнал, статистика, синк MT, проп-правила, разборы, ИИ), сетка 3×2.
3. «Тарифы» — 4 карточки Free / Solo $17 / Trader $29 / Pro $59, строки с галочками.
4. Футер: ссылки + дисклеймер.

## Проблемы, замеченные сразу

- **Продукт не показан ни разу**: ни скриншота, ни графика.
- Структура = типовой ИИ-шаблон (надзаголовок капсом, стеклянная карточка, 3×2 карточки с иконками, тарифы).
- **Ошибки в тарифах**: Free «Торговые счета · 5», Solo «· 1» — по документации на Free 1 счёт. У Pro ИИ «Sonnet», по документации Opus. Автоматизация — непонятно, что это.
- Надзаголовок «без регистрации» висит над продуктом, где регистрация нужна (относится к бесплатным инструментам).
- 4 равноценных действия в hero, нет главного.
- Нет: живых проп-правил (главное отличие), «цифры брокера не подделать», верифицированных карточек, соцдоказательств, FAQ, ответа на «безопасно ли давать пароль MT» (investor-пароль, только чтение).
- Нет мобильного приложения/скриншотов мобайла, нет каталога проп-фирм как витрины.

## Scope360 — что у них работает

- Hero: короткий слоган «Know your edge. Trade with confidence» + большой скриншот таблицы журнала сразу под ним.
- Trustpilot сразу после hero.
- Тур по продукту вкладками: Dashboard / Journal / AI Assistant / Calendar / Position / Notes.
- Интерактивная форма подключения биржи прямо на лендинге.
- «Ручной журнал бесплатно навсегда» отдельным блоком.
- ИИ, мобильное приложение (iOS/Android), таблица сравнения «Scope vs Other», FAQ, тарифы (помесячно/год −15%), Discord.
- Скролл-анимации (контент появляется только при скролле — минус для скорости и доступности).
- Визуально не сильно лучше, но **показывают продукт**.

## Чем Traders Care может выиграть у Scope360

- Живой контроль правил проп-фирм (просадка static/trailing/EOD, consistency, вердикты OK/WARNING/BREACH).
- Цифры брокера нельзя подделать → верифицированные карточки и профили (`/v/[code]`, `/u/[handle]`).
- Каталог проп-фирм + квиз подбора + активация счёта с правилами программы.
- Торговая система (доктрина → правила → сетапы) и цена отступления от неё.
- Бесплатные калькуляторы.
- Оплата криптой без автосписаний; 3 языка включая RU/UK.
