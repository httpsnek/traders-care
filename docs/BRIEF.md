# Бриф

## Клиент и продукт

**Traders Care** (traderscare.io) — рабочее место трейдера: журнал сделок с автосинхронизацией брокера (MetaTrader, cTrader, Match-Trader, DXtrade), аналитика, живой контроль правил проп-фирм, торговая система, ИИ-ассистент, каталог проп-фирм.
ЦА: проп-трейдеры (сдают челленджи, боятся нарушить лимит просадки) и системные трейдеры с несколькими счетами.
Одна фраза продукта: помогает торговать по своим правилам и видеть, во что обходится каждое отступление.

Полная документация (читать через Artifact read):
- Бриф для дизайнера: https://claude.ai/artifact/JzMWBLBuLLK2xoYGERjjhQ
- Продуктовый гид по всем страницам: https://claude.ai/artifact/5wzaJJHtT3MSj2mCztR1cB

## Задача (этап 1 отношений с клиентом)

Редизайн **лендинга** https://traderscare.io/ru — чтобы клиент захотел продолжить работу (дальше — редизайн всего приложения).

Главный запрос клиента: **премиальный дизайн, который не выглядит сделанным ИИ.**

Сдаём **рабочей вёрсткой**, не макетами.

Что не берём: неоновые кольца-прогрессы, портфолио-штампы.

## Инструменты

- ИИ-генерация изображений — только объекты, материалы, свет, окружение. Без людей.
- Morphicons (https://www.morphicons.com/) — морфинг SVG-иконок, React, работает с Lucide. Точечно, 3–5 мест, с вариантом для reduced motion.

## Жёсткие ограничения (из документации клиента)

- Зелёный/красный — только P&L. Бренд-акцент сейчас фиолетовый `#8D7CF8`.
- Тёмная и светлая тема (светлая — не инверсия).
- WCAG AA: текст 4.5:1, границы контролов 3:1.
- EN / RU / UK, русский/украинский длиннее на 20–40%.
- Продукт не даёт торговых сигналов — копирайт говорит «анализ», не «покупай».
- Шрифт SF Pro нелегален в вебе вне Apple — повод выбрать новый.
