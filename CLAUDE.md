# Traders Care — редизайн лендинга

Работаем вдвоём: Никита (дизайнер/исполнитель перед клиентом) и Claude.
Язык общения — русский.

## Как начинать каждую сессию

1. Прочитать `docs/PLAN.md` — где мы сейчас и что следующее.
2. Прочитать последние записи в `docs/LOG.md`.
3. При необходимости — `docs/BRIEF.md, docs/QUESTIONS.md` (задача, ограничения) и `docs/DECISIONS.md` (что уже решено, не переобсуждать).

## Как вести документы

- `PLAN.md` — этапы и задачи с чекбоксами. Отмечаем `[x]` сразу по факту выполнения.
- `LOG.md` — в конце каждой рабочей сессии: дата, что сделано, что осталось, на чём остановились. Новые записи сверху.
- `DECISIONS.md` — каждое принятое решение одной строкой с датой и причиной.
- `research/` — сырые наблюдения, аудит, референсы.

Работаем поэтапно: не переходим к следующему этапу, пока Никита не подтвердил текущий.

## Главные правила дизайна

- Премиально и **не похоже на ИИ-шаблон**: без надзаголовков капсом над каждым блоком, без сетки 3×2 из карточек с иконками, без неоновых колец и blob-фонов, без «появления всего подряд» при скролле. Одна сильная визуальная идея на блок.
- Главный визуал — **сам продукт** (экраны интерфейса в новом стиле, с правдоподобными данными). ИИ-генерация — только предметы, материалы, свет, сцены. **Никаких людей.**
- Роли цветов Traders Care не ломаем: зелёный/красный — только прибыль/убыток.
- EN / RU / UK, тёмная + светлая тема, мобильная версия, WCAG AA, reduced motion.

## Стек вёрстки

Совпадает со стеком клиента, чтобы перенос был копированием, а не переписыванием:
Next.js 15 (App Router) + React 19 + TypeScript + Tailwind 3 + motion + lucide-react + morphicons.

## Запуск

`npm run dev` → http://localhost:3010 (EN `/`, `/ru`, `/uk`, служебная `/ru/system`).
TypeScript закреплён на 5.9: TS 7 ломает загрузку next.config.ts в Next 15.
Код: `src/app/[locale]`, секции `src/components/sections`, шапка и прочее `src/components/site`, тексты `src/i18n/dictionaries` (ru — исходный, от него тип).


## Наполнение
Никита отвечает за визуал, не за контент. Вопросы по данным (тарифы, фирмы, ссылки, цифры) не задаём ему — дописываем в `docs/QUESTIONS.md`, в коде ставим правдоподобную заглушку с пометкой `[ДАННЫЕ]`.
